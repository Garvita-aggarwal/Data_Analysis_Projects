# 📊 Data Analysis Projects

Welcome to my **Data Analysis Projects** repository. This portfolio contains projects focused on data cleaning, exploratory data analysis, business insights, visualization, and dashboard development.

## 🛠️ Tools & Technologies

* **Python** – Pandas, NumPy, Matplotlib
* **SQL** – Data extraction, filtering, joins, aggregations, analysis
* **Microsoft Excel** – PivotTables, PivotCharts, Power Query, Dashboards
* **Power BI** – Data Modeling, DAX, KPIs, Interactive Dashboards

## 📂 Projects

### ☕ Coffee Sales Analysis Dashboard

**Tools:** Microsoft Excel

Analyzed coffee sales data to identify sales trends, top-performing products, store performance, and key business KPIs.

**Outcome:** Built an interactive Excel dashboard to support sales monitoring and data-driven decision-making.

---

### 📡 Telecom Customer Churn Analysis

**Tools:** Python, Pandas, NumPy, Matplotlib, SQL

Analyzed customer data to identify churn patterns, customer segments, and factors associated with customer attrition.

**Outcome:** Identified churn trends and generated insights that can help improve customer retention strategies.

---

### 💰 Retail Price Optimization

**Tools:** Python, SQL

Analyzed retail pricing and product data to understand pricing patterns, demand, and revenue opportunities.

**Outcome:** Developed analytical insights to support better pricing and revenue decisions.

---

### 📱 PhonePe Transaction Analytics Dashboard

**Tools:** Power BI, DAX

Analyzed transaction data to understand transaction volume, value, user activity, and geographic trends.

**Outcome:** Created an interactive Power BI dashboard for monitoring transaction performance and identifying trends.

---

### 🛒 Superstore Sales Analysis

**Tools:** Excel, SQL

Analyzed sales, profit, products, customers, and regional performance using SQL and Excel.

**Outcome:** Identified key sales and profitability trends to support business performance analysis.
